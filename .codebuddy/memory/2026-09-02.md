### ⚠️ F19 关键 bug 修复（用户反馈"点不动"后定位）
- **真正根因**：`dashboard_html()` 是 Python 三引号字符串，内嵌 JS 中 `txt.split('\n')`（第711行 `createMonitor`）的 `\n` 被 **Python 当成转义吃掉变成真实换行**，破坏 JS 单引号字符串 → 整个 `<script>` 解析失败 → 所有 onclick 失效 → 页面"到处点不动"。
- **修复**：改为 `txt.split(String.fromCharCode(10))`，避开反斜杠转义。并用 `node --check` 提取页面 JS 验证语法全 OK。
- **教训（跨会话）**：在 Python 三引号/f-string 里内嵌 HTML/JS/CSS 时，**任何 `\n`/`\t`/`\.`/`\/` 等反斜杠序列都会被 Python 解释**，导致前端语法错误且极难发现（后端路由/接口都正常，只有浏览器执行才暴露）。
  - 写前全局搜 `\\n`/`\\t`/`\\.` 确认无裸反斜杠；正则/换行用 `String.fromCharCode` 或 `%0A`/JSON 转义替代。
  - 验收 UI 不能只查后端路由/页面含字符串，**必须用 `node --check` 或 headless 浏览器验证 `<script>` 语法可执行**（本次 F19 因只测后端链路漏掉此问题）。
  - 验证法：`node` 抓取 `/` 页面抽 `<script>` 存文件，`node --check _tmp_page.js` 查语法。
